Deskripsi : Permainan tebak kata dimana user menebak kata rahasia yang terdiri dari 5 huruf dengan batas maksimal enam kali percobaan (Replika dari game berbasis web "Wordle")

Fitur : 
-GUI grid 6x5
-GUI keyboard di layar user (menerima input keyboard virtual/fisik)
-Validasi kata, indikator warna (Hijau = huruf benar dan posisi benar, Kuning = huruf benar dan posisi salah, Abu-abu = huruf tidak ada dalam kata)
-Light mode/dark mode
-Pesan status (kata tidak ada dalam kamus, kata berhasil ditebak, dan game over)
-Halaman tutorial cara bermain
